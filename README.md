# Stationary bistable fronts on a periodic necklace graph

Interactive slides of a talk given to the Applied Mathematics group at the University of Pennsylvania,
30 October 2026.

**Open the slides: <https://mathmd.github.io/necklace-talk/>**

Paper: Y. Mori, T. Ogawa, C. Sintavanuruk,
*Stationary bistable fronts on a periodic necklace graph: existence, stability and multiplicity*,
[arXiv:2610.32917](https://arxiv.org/abs/2610.32917).
Statements, hypotheses and proofs are in the paper; the slides show the ideas and computed pictures.

## Using the slides

- <kbd>→</kbd> or <kbd>Space</kbd> (or the **›** button) moves on; <kbd>←</kbd> goes back.
- On many slides the figures can be changed: the lines that can be dragged are shaded when a slide opens
  and while the pointer is over the figure, and the line under each figure lists what can be changed there
  and the matching keys. On a touch screen, drag with a finger.
- **Notes** (<kbd>n</kbd>) shows the speaker's notes for each slide; **Sliders** (<kbd>c</kbd>) shows a slider
  for each quantity; <kbd>?</kbd> explains the controls.

The slides run in any current browser and need no installation.
To run them from a copy of this repository, serve the folder over HTTP, for example
`python3 -m http.server`, and open <http://localhost:8000>;
opening `index.html` directly from disk does not work, because the page loads its slides with `fetch`.
